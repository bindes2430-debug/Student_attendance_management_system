# Project Statement

# Project Title

Student Attendance Management System

## Problem Statement

Maintaining student attendance manually can take time and may cause mistakes.

This project provides a simple Python program that stores student details and attendance records.

# Objectives

The main objectives are:

1. To store student information.
2. To mark student attendance.
3. To calculate attendance percentage.
4. To display attendance reports.
5. To practice Python programming concepts.

# Scope

The project covers:

- Student management
- Attendance marking
- Attendance report

The project is designed for a small classroom.

# Target Users

- Teachers
- Class representatives
- Students learning Python

# Functional Requirements

1. The user can add a student.
2. The user can view students.
3. The user can delete a student.
4. The user can mark attendance.
5. The system can calculate attendance percentage.
6. The system can display attendance reports.

# Design Approach

The project uses beginner-level Python concepts including:

- Input and Output
- Variables
- Operators
- Conditional Statements
- Loops
- Lists
- Strings
- Functions
- Modules
- File Handling

# Future Enhancements

In the future, the project can include:

- Student search
- Student update
- Monthly attendance report
- Login system
- Graphical interface
