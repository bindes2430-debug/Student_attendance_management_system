# Student Attendance Management System

# Project Overview

This is a simple Python-based Student Attendance Management System.

The project is made for a small classroom and helps manage student information and attendance records.

# Features

1. Add Student
2. View Students
3. Delete Student
4. Mark Attendance
5. View Attendance Report
6. Calculate Attendance Percentage

# Technologies Used

- Python
- Functions
- Variables
- Operators
- If-else
- Loops
- Lists
- Strings
- File Handling
- Python Modules

No external libraries are used.

# How to Run

Install Python 3.

Open the project folder in Command Prompt.

Run:

python main.py

# Testing

Run:

python test_project.py

# Data Storage

Student information is stored in students.txt.

Attendance information is stored in attendance.txt.
